# 03. 월드와 레벨 (컨텐츠)

## 월드 지도

```
                     [얼음 궁전]  ← 챕터 4 (얼음으로 만든 공간)
                          ▲
                    [괴물 동굴]  ← 챕터 3 (동굴을 지나서)
                          ▲
                 [구멍 뚫린 들판]  ← 챕터 2 (구멍이 뚫려 있음)
                          ▲
   [놀이터] ── [마을(허브)] ── [숫자 초원]  ← 챕터 1
                 큰 숫자 나무
```

지역은 이어져 있고, 각 지역 사이에는 "관문"이 있다. 관문은 숫자블록 창고에 특정 크기의 블록이 있어야 열린다.

| 관문 | 여는 조건 |
|------|-----------|
| 초원 → 들판 | 5 블록 1개 (초원에서 블록 5개 모으기) |
| 들판 → 동굴 | 10 블록 1개 + 쿵쿵이 진정시키기 |
| 동굴 → 얼음 궁전 | 우르릉과의 크기 비교 대결 승리 |

---

## 지역 0. 마을(허브)

- 큰 숫자 나무를 중심으로 한 작은 마을. 처음엔 얼어 있고, 챕터를 깰수록 조금씩 녹는다.
- 구출한 숫자블록 친구마다 집이 하나씩 생긴다(1의 집은 블록 1개짜리, 5의 집은 블록 5개짜리로 크기가 다름).
- **놀이터**: 미니게임 입구. 잡은 몬스터들이 뛰어놀고 있다.
- **창고**: 모은 숫자블록이 실제 3D 블록으로 쌓여 있어서 얼마나 모았는지 한눈에 보인다.
- **도감 게시판**: 잡은 몬스터 그림이 붙는다.

## 지역 1. 숫자 초원 (챕터 1)

| 항목 | 내용 |
|------|------|
| 분위기 | 밝고 넓은 풀밭, 낮은 언덕, 꽃, 나비 |
| 배우는 것 | 1~5 세기, 이동/점프/액션 |
| 출현 몬스터 | 뽀글이(3), 폴짝이(2), 꼬물이(1) |
| 숫자블록 친구 | 둘이(2), 셋이(3) |

레벨 구성:

1. **1-1 첫걸음**: 원이 따라가기. 블록 3개 줍기 튜토리얼.
2. **1-2 풀숲 숨바꼭질**: 풀숲에 숨은 뽀글이가 다가온다. 첫 포획.
3. **1-3 언덕 위 둘이**: 언덕 꼭대기에 둘이가 갇혀 있다. 점프 튜토리얼. 폴짝이 출현.
4. **1-4 나비 세기**: 꽃밭의 나비 수를 세서 셋이의 문을 연다.
5. **1-5 큰 구멍 앞에서**: 5 블록을 만들어 관문 열기. 챕터 종료.

## 지역 2. 구멍 뚫린 들판 (챕터 2)

| 항목 | 내용 |
|------|------|
| 분위기 | 갈라진 땅, 크고 작은 구멍, 구멍 아래는 푹신한 지하 |
| 배우는 것 | 더하기(합이 5까지 → 10까지) |
| 출현 몬스터 | 두더구(4), 방울이(5), 데굴이(6) |
| 숫자블록 친구 | 넷이(4), 다섯이(5) |
| 파트너 능력 활용 | 두더구: 구멍 파기 → 숨은 블록 발견 |

핵심 메카닉 **더하기 다리**:

- 구멍 앞에 서면 구멍 폭이 숫자로 표시된다(예: 5칸).
- 가진 블록 중 두 개를 골라 합쳐서 폭과 같으면 다리가 놓인다(2+3, 1+4, 5 단독도 가능).
- 다리는 실제로 블록 두 개가 이어져 색이 두 가지로 보인다 → "5는 2와 3으로 되어 있어" 시각화.

구멍 종류:

| 구멍 | 폭 | 특징 |
|------|----|------|
| 작은 구멍 | 1~2 | 점프로 그냥 건널 수 있음. 떨어져도 바로 올라옴 |
| 중간 구멍 | 3~5 | 더하기 다리 필요 |
| 큰 구멍 | 6~10 | 더하기 다리 필요. 아래에 지하 보물방이 있음 |
| 함정 구멍 | - | 풀로 덮여 있어 안 보임. 떨어지면 지하로. 지하에서 두더구를 만남 |

레벨 구성:

1. **2-1 첫 다리**: 폭 3 구멍. 1+2 다리 놓기.
2. **2-2 지하 세계**: 함정 구멍에 빠져 지하로. 두더구 포획, 구멍 파기 배우기.
3. **2-3 넷이 구출**: 폭 4 구멍 세 개를 연속으로 건너 넷이 구출.
4. **2-4 방울 들판**: 방울이가 떠다니는 언덕. 합이 5인 다리 여러 번.
5. **2-5 다섯이의 다섯 구멍**: 폭 5~7 구멍 다섯 개. 다섯이 구출.
6. **2-6 동굴 입구, 쿵쿵이**: 폭 10 구멍(합 10 다리) 후 쿵쿵이 진정시키기(10 만들기 첫 등장).

## 지역 3. 괴물 동굴 (챕터 3)

| 항목 | 내용 |
|------|------|
| 분위기 | 어둡고 축축한 동굴, 반짝이는 광석, 지하 호수, 종유석 |
| 배우는 것 | 빼기(10 이내), 크다/작다 비교 |
| 출현 몬스터 | 반디(7), 바위돌이(8), 박쥐돌이(9) |
| 괴물(적) | 그림자 괴물 x3 (숫자 5/7/9), 중간 보스 우르릉 |
| 숫자블록 친구 | 여섯이(6), 일곱이(7), 여덟이(8) |
| 파트너 능력 활용 | 반디: 주변 밝히기 / 바위돌이: 바위 밀기 |

핵심 메카닉:

- **어둠**: 반디를 잡기 전에는 플레이어 주변만 보인다. 반디를 잡으면 시야가 넓어진다.
- **괴물 진정시키기(빼기)**: 괴물 머리 위 숫자(예: 7). 내가 들고 있는 블록(예: 10)에서 몇 개를 빼야 7이 되는지 맞춘다. 맞추면 괴물이 코 골며 잠든다.
- **괴물에게 잡히면**: 화면이 잠깐 까매지고 동굴 입구(또는 체크포인트)로 돌아간다. 블록은 잃지 않는다.
- **동굴 지하 호수**: 데굴이 몬스터를 타고 건넌다. 물 위 징검다리는 숫자 순서대로(1→2→3…) 밟아야 한다.

레벨 구성:

1. **3-1 캄캄한 입구**: 반디 잡기. 시야 확보.
2. **3-2 첫 그림자 괴물**: 숫자 5 괴물. 빼기 튜토리얼(10 - 5).
3. **3-3 여섯이의 광석방**: 반짝이는 광석 개수를 세고 빼기로 문 열기. 여섯이 구출.
4. **3-4 지하 호수 징검다리**: 숫자 순서 징검다리. 일곱이 구출.
5. **3-5 여덟이와 벽 타기**: 여덟이가 벽을 타고 올라 길을 만들어 줌. 박쥐돌이 포획.
6. **3-6 우르릉의 방**: 중간 보스. 크기 비교 대결 3라운드.

## 지역 4. 얼음 궁전 (챕터 4)

| 항목 | 내용 |
|------|------|
| 분위기 | 벽·바닥·계단·문이 전부 얼음. 안이 비쳐 보이는 반투명 파랑. 눈이 내림 |
| 배우는 것 | 10 만들기(10의 보수), 11~20 세기 |
| 출현 몬스터 | 불꽃이(10), 눈송이(12), 펭구(15) |
| 괴물(적) | 얼음 병정 x4 (숫자 11~14), 최종 보스 빙빙왕 |
| 숫자블록 친구 | 아홉이(9), 열이(10) |
| 파트너 능력 활용 | 불꽃이: 얼음 녹이기 / 펭구: 미끄러운 바닥에서 안 미끄러짐 |

핵심 메카닉:

- **미끄러운 바닥**: 한 번 움직이면 벽에 닿을 때까지 미끄러진다(퍼즐 요소). 펭구를 파트너로 하면 보통처럼 걸을 수 있다.
- **10 자물쇠 문**: 문에 숫자(예: 6)가 적혀 있고, 10이 되도록 나머지(4) 블록을 끼우면 녹는다.
- **얼음 속 친구 구출**: 불꽃이의 능력으로 얼음을 녹여 아홉이, 열이 구출.
- **얼음 병정**: 괴물 숫자가 11~14로 커진다. "10 블록 + 몇 개"로 보여주면 잠든다(11~20을 10과 나머지로 보는 연습).

레벨 구성:

1. **4-1 미끄럼 복도**: 미끄러지는 바닥 튜토리얼.
2. **4-2 첫 얼음 문**: 10 만들기 문. 불꽃이 포획.
3. **4-3 아홉이의 얼음방**: 불꽃이로 녹이기. 얼음 병정 2명.
4. **4-4 눈송이 정원**: 눈송이 몬스터 포획(12). 11~15 세기.
5. **4-5 열이의 탑**: 나선 계단, 10 자물쇠 문 5개 연속. 펭구 포획, 열이 구출.
6. **4-6 빙빙왕의 방**: 최종 이벤트. 1~10 순서대로 보여주기 → 20까지 세기 파티.

## 자유 탐험 (엔딩 후)

- 모든 지역이 열리고, 낮/밤이 바뀌며 밤에만 나오는 몬스터 1마리(달빛이, 숫자 20)가 추가된다.
- 각 지역에 숨은 **황금 블록** 5개씩. 전부 모으면 놀이터에 "20까지 대모험" 미니게임이 열린다.
