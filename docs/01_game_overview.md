# 01. 게임 개요 및 구성

## 한 줄 소개

숫자블록 친구와 함께 넘버랜드를 탐험하며, 겁먹고 도망친 몬스터들을 **숫자 놀이로 잡아 친구로 만들고**, 잡은 몬스터와 숫자블록으로 미니게임을 하면서 얼음에 갇힌 세계를 녹이는 3D 어드벤처.

## 기본 정보

| 항목 | 내용 |
|------|------|
| 가제 | 넘버 몬스터 어드벤처 (Number Monster Adventure) |
| 장르 | 3D 탐험 어드벤처 + 몬스터 수집 + 숫자(수학) 미니게임 |
| 대상 | 5~8세 (가정: 넘버블럭스를 보는 나이대. 숫자 범위는 1~20까지) |
| 플랫폼 | PC 웹브라우저 (키보드/게임패드), 추후 태블릿 터치 |
| 플레이 시간 | 한 챕터 10~15분, 전체 4챕터 + 자유 탐험 |
| 폭력 수위 | 없음. 괴물은 "쓰러뜨리는" 게 아니라 "숫자로 진정시켜서" 친구로 만듦 |

## 핵심 루프 (Core Loop)

```
탐험하기 ──▶ 몬스터 만나기 ──▶ 숫자 놀이로 잡기 ──▶ 파트너로 데리고 다니기
   ▲                                                       │
   │                                                       ▼
새 지역 열림 ◀── 숫자블록 보상 ◀── 잡은 몬스터 + 숫자블록으로 미니게임
```

1. **탐험**: 3D 맵을 뛰어다니며 구멍을 건너고, 동굴을 지나고, 숨어 있는 숫자블록 조각을 찾는다.
2. **만남**: 몬스터는 맵을 돌아다니다가 플레이어가 가까이 오면 다가온다("포켓몬이 오면").
3. **잡기(포획)**: 몬스터마다 "좋아하는 숫자"가 있다. 숫자블록을 그 숫자만큼 쌓아 보여주면 몬스터가 안심하고 친구가 된다. (자세한 규칙은 아래)
4. **파트너**: 잡은 몬스터 1마리가 플레이어를 따라다니고, 몬스터마다 탐험 능력이 하나씩 있다(구멍 건너뛰기, 얼음 녹이기 등).
5. **미니게임**: 마을의 놀이터에서 잡은 몬스터들과 숫자블록으로 게임을 한다. 이기면 숫자블록이 늘어나고, 큰 숫자블록이 모이면 새 지역 문이 열린다.

## 포획 규칙 (전투 장면) — 프로토타입 구현됨

몬스터와 닿으면 화면이 전투 시점(주인공 어깨 뒤에서 몬스터를 마주 봄)으로 바뀐다. 시간 제한은 없다.

1. **몬스터 체력 = 좋아하는 숫자.** 화면 아래에 체력이 색깔 블록으로 표시된다(뽀글이는 노란 블록 3개).
2. **숫자블록 던지기.** 던질 개수 n을 고르고 던지면 숫자블록 n이 포물선으로 날아가 체력을 n만큼 깎는다. 체력을 **딱 0**으로 만들어야 한다. 남은 체력보다 많이 던지면 "너무 많아!" 하고 튕겨 돌아온다(블록은 그대로).
3. **숫자볼 던지기.** 체력이 0이 되면 몬스터가 어질어질해지고 숫자볼 버튼이 나온다. 볼이 날아가 몬스터를 담고, 땅에 떨어져 3번 흔들린 뒤 "잡았다!" — 별이 터지고 색종이가 내리고 팡파레가 울린다.
4. 던진 블록은 몬스터에게 준 것이라 사라진다(잡는 데 드는 블록 = 좋아하는 숫자). 체력은 몬스터마다 기억되므로 블록이 모자라면 나갔다가 더 모아서 이어서 던질 수 있다.
5. 벌칙은 없다. "나중에"로 언제든 나갈 수 있고, 몬스터는 잠시 물러났다가 다시 온다.

배우는 것: 세기, 빼기(체력 3에서 2를 던지면 1), 수 분해(3 = 2 + 1), 10 만들기(보스 체력 10).

## 진행 구조

| 순서 | 지역 | 배우는 숫자 개념 | 주요 컨텐츠 |
|------|------|------------------|-------------|
| 챕터 1 | 숫자 초원 (시작 마을) | 1~5 세기 | 조작 익히기, 첫 몬스터 잡기, 놀이터 열기 |
| 챕터 2 | 구멍 뚫린 들판 | 더하기 (5까지 → 10까지) | 블록을 합쳐 다리를 놓아 구멍 건너기 |
| 챕터 3 | 괴물 동굴 | 빼기, 크다/작다 비교 | 어두운 동굴, 괴물 피하기/진정시키기, 중간 보스 |
| 챕터 4 | 얼음 궁전 | 10 만들기, 20까지 세기 | 얼음으로 만든 방들, 미끄러운 바닥, 최종 보스 "빙빙왕" |
| 이후 | 자유 탐험 | 복습 | 못 잡은 몬스터 모으기, 미니게임 최고 기록 |

## 조작 (아이 기준으로 최소화)

| 동작 | 키보드 | 게임패드 | 터치(추후) |
|------|--------|----------|-----------|
| 이동 | 방향키 / WASD | 왼쪽 스틱 | 가상 스틱 |
| 점프 | 스페이스 | A | 점프 버튼 |
| 액션(말 걸기/블록 놓기/파트너 능력) | E 또는 엔터 | B | 액션 버튼 |
| 파트너 바꾸기 | Q | Y | 파트너 아이콘 |
| 일시정지 | ESC | Start | 메뉴 버튼 |

- 버튼은 딱 3개(이동, 점프, 액션)만 알면 게임 전체를 할 수 있다.
- 구멍에 떨어지면 죽지 않고 바로 근처 땅으로 "뿅" 하고 올라온다. 게임오버 없음.

## 화면 흐름

```
타이틀 ─▶ 세이브 고르기(그림 3칸) ─▶ 마을(허브)
                                      ├─▶ 지역 탐험 (챕터 맵) ─▶ 잡기 모드 ─▶ 마을로 복귀
                                      ├─▶ 놀이터 (미니게임 선택)
                                      ├─▶ 몬스터 도감 / 숫자블록 창고
                                      └─▶ 설정
```

## 보상과 수집 요소

- **숫자블록**: 미니게임/탐험에서 얻는 기본 재화. 1블록 단위로 모이고, 10개가 모이면 자동으로 "10 블록"이 되어 창고에 세워진다.
- **몬스터 도감**: 잡은 몬스터의 그림, 좋아하는 숫자, 능력, 잡은 곳이 기록된다. 총 16마리(드래프트).
- **숫자블록 친구 구출**: 각 지역에 흩어진 숫자블록 친구(1~10)를 찾아 마을로 데려온다. 데려오면 마을에 그 친구의 집이 생기고 새로운 미니게임이 열린다.
- **스티커**: 미니게임 최고 기록 달성 시 스티커를 받아 세이브 화면을 꾸민다.
