# 넘버 몬스터 어드벤처 (Number Monster Adventure) — 가제

아이와 함께 만드는 3D 어드벤처 + 숫자 놀이 게임입니다.

## 아이가 적어준 원래 아이디어 (2026-09-10)

1. 넘버블럭스랑 포켓몬이 오면 잡아서, 그 잡은 포켓몬이랑 넘버블럭스로 게임을 할 수 있다.
2. 일부 구멍도 뚫려있고, 괴물도 있고, 동굴을 지나서 얼음으로 만들어진 공간이 있게 해주세요.
3. 포켓몬은 저작권 때문에 나중에 3D 이미지 파일을 별도로 올려서 대체할 예정. 지금은 draft 캐릭터로 OK.

## 지금 바로 플레이 (챕터 1 프로토타입)

- 브라우저에서 열기: **https://merrypapa.github.io/number-pokemon/**
- 조작: 방향키/WASD 이동, 스페이스 점프, E 액션. 태블릿에서는 화면 버튼이 나옵니다.
- 할 수 있는 것:
  - **시작**: 타이틀에서 새로하기(주인공 이름 짓기 → 내 포켓몬 고르기) 또는 이어서하기(저장된 유저 이름 목록에서 선택). 게임 중 💾 저장 버튼으로 언제든 저장하고, 몬스터를 잡거나 지역을 옮기거나 90초마다 자동 저장된다. 저장은 브라우저 localStorage 에 남아 브라우저를 다시 열어도 유지된다(같은 기기·같은 브라우저). 잡은 포켓몬 중 대표 한 마리만 따라다니며 싸운다.
  - **도감 지도 탭**: 다섯 지역을 그림 지도로 보여준다. 정복한 지역은 색과 ★, 아닌 곳은 회색. 지역을 누르거나 ◀ ▶ 버튼으로 넘기면 설명·가는 길·그 지역 포켓몬(잡은 것은 컬러, 못 잡은 것은 실루엣, 보스 표시)이 나온다.
  - **지역 5곳**: 푸른숲(시작 마을, 220×220, 풀·노말·벌레·전기) · 지하동굴(160×160, 땅·바위·독, 어둡고 호수·다리·빛나는 웅덩이) · 불의산(220×220, 불, 큰 화산과 작은 화산·용암 웅덩이·간헐천·흑요석 아치) · 물의길(180×180, 물, 다리로 이어진 모래섬) · 꿈의우주(220×220, 페어리·에스퍼·고스트, 별하늘·유성·인공위성, 화면을 위로 밀어 올려다보면 태양과 수·금·지·화·목·토·천·해·명왕성, 약한 중력). 포켓몬은 속성에 맞는 지역에 산다.
  - **지역 이동**: 푸른숲 큰 구멍/북쪽 산 입구 → 지하동굴, 동북쪽 붉은 바위 아치 → 불의산, 서쪽 기차역에서 E → 기차 타고 물의길, 남동쪽 로켓 발사장에서 E → 로켓 타고 꿈의우주. 지하동굴·불의산은 빛나는 포탈로, 물의길은 그곳 기차역의 기차로, 꿈의우주는 착륙장의 로켓으로 푸른숲에 돌아온다.
  - **보스와 정복**: 지역마다 크고 센 보스(이상해꽃·롱스톤·리자몽·거북왕·뮤)가 금빛 고리와 이름표를 달고 있다(푸른숲 아레나, 지하동굴 북쪽, 불의산 꼭대기, 물의길 남쪽 끝 섬, 꿈의우주 북쪽 제단). 보스를 잡으면 그 지역 정복(HUD ★, 도감 "정복 n/5"). 푸른숲 보스를 잡으면 지하동굴 입구 바위가 치워진다.
  - **포켓몬 대결**: 내 대표 포켓몬이 기술로 공격 → 상대가 반격 → 상대 체력 0이면 숫자볼로 캡처. 도감(B)은 내 포켓몬 칩과 선택한 한 마리의 상세(스탯·기술·진화·키우기·대표·진화 버튼) + 아래 액자 그리드(액자를 누르면 상세가 바뀜). 같은 종을 또 잡으면 파티에 새로 들어오지 않고 도감의 누적 마리 수만 오르며, 진화하려면 공격 10·체력 15에 더해 그 종을 누적 3마리 잡아야 한다.
  - **숫자블록 구출**: 지역마다 45~90초에 한 번 숫자블록 친구(2~10)가 랜덤한 곳에 나타나 도와달라고 한다(말풍선이 방향을 알려 줌). 가까이 가서 E를 누르면 포켓몬 마리 수 문제가 나오고, 맞히면 그 숫자만큼 내 숫자블록에 합쳐진다. 숫자가 클수록 어렵다: 세기(2~3) → 더하기(4~5) → 빼기(6~7) → 10 만들기(8~9) → 세 무리 더하기(10). 120초 안에 못 구하면 다른 곳으로 간다.
  - 하얀 블록 줍기(30개까지, 주운 블록이 숫자블록이 되어 따라옴), 나무·집·바위 같은 구조물은 지나갈 수 없고 물·용암은 다리로만 건넌다.

로컬에서 실행하려면 저장소 폴더에서 정적 서버를 하나 띄우면 됩니다(빌드 없음).

```
python3 -m http.server 8000
# 그 다음 브라우저에서 http://localhost:8000 열기
```

코드 구조:

| 경로 | 내용 |
|------|------|
| `index.html`, `style.css` | 화면(HUD, 잡기 창, 터치 버튼) |
| `src/main.js` | 게임 루프, 상태, 지역 지연 생성(타이틀 먼저 → 푸른숲 → 처음 갈 때 나머지), 새로하기/이어서하기/저장, 지역 이동(기차·로켓·포탈), 보스 정복, 숫자블록 랜덤 구출, 튜토리얼 |
| `src/world.js` | 푸른숲 지형(나무·바위·덤불·구름은 InstancedMesh 로 한 번에 그린다)(언덕·구멍·나무·꽃·마을), 불의산 입구·기차역·로켓 발사장, 나무 다리, 물 막기(`isBlocked`)와 구조물 충돌(`resolveObstacles`), 지역 공용 헬퍼(바닥·포탈·표지판) |
| `src/cave.js`, `src/volcano.js`, `src/sea.js`, `src/space.js` | 지하동굴 · 불의산 · 물의길 · 꿈의우주 지역 (지형, 장식, 몬스터/블록 자리, 포탈) |
| `src/quiz.js` | 숫자블록 구출 문제 (포켓몬 마리 수 세기·더하기·빼기·10 만들기) |
| `src/save.js` | 저장/불러오기 (localStorage, 유저 이름별) |
| `src/player.js` | 주인공 이동/점프/구멍 낙하 |
| `src/creatures.js` | `data/creatures.json`의 draftShape로 드래프트 몬스터 생성, 다가오기 AI |
| `src/party.js` | 내 포켓몬(파티): 스탯·기술 해금·블록으로 강화·진화·패배 시 체력 리셋 |
| `src/models.js` | `assets/models/*.glb` 불러오기(GLTFLoader), 드래프트 도형 → 진짜 모델 교체, 애니메이션 |
| `src/intro.js` | 시작 화면 3D 무대(주인공·몬스터 친구들·떠다니는 숫자블록) |
| `tools/shrink_glb.py` | .glb 텍스처 줄이기(로딩 속도) |
| `src/palette.js` | 숫자별 색 (number-mario 와 동일 팔레트) |
| `src/numberblocks.js` | 숫자블록 친구(숫자별 색·배치·얼굴·팔다리), 파트너 줄지어 따라오기 |
| `src/battle.js` | 대결 장면(어깨 뒤 시점, 턴제: 내 포켓몬 기술 → 상대 반격, 체력 0이면 숫자볼 캡처, 승리/패배 연출) |
| `src/dex.js` | 도감 + 내 포켓몬 패널(대표 고르기, 블록으로 공격/체력 올리기, 진화) |
| `src/effects.js` | 색종이, 별/조각 파티클, 합성 효과음 |
| `vendor/three/` | Three.js 0.170 (MIT) 로컬 복사본 + GLTFLoader/SkeletonUtils 애드온 |
| `.github/workflows/pages.yml` | main에 푸시하면 GitHub Pages로 자동 배포 |

## 저작권 메모

- **포켓몬**: 게임 안의 몬스터는 전부 이 프로젝트에서 새로 만든 드래프트 캐릭터입니다. 나중에 개인용 3D 파일로 교체할 때는 `assets/models/`에 넣고 `data/creatures.json`의 `model` 값만 바꾸면 됩니다.
- **넘버블럭스(Numberblocks)**: BBC/Alphablocks Ltd 의 상표·캐릭터입니다. 이 프로젝트의 "숫자블록" 친구들은 number-mario 프로젝트와 같은 자체 팔레트(`src/palette.js`)와 코드로 그린 자체 디자인이며, 원작의 이미지·모델 파일은 쓰지 않습니다. 집에서 아이와 즐기는 개인 프로젝트로는 문제 없지만, 공개 배포 시에는 이름과 디자인이 원작과 겹치지 않게 유지해 주세요.
