# assets/models

3D 모델(.glb) 파일을 넣는 폴더입니다.

- 파일 이름은 `data/creatures.json` / `data/numberblocks.json`의 `id`로 시작하게 해주세요. 예: `m03_bbogeul.glb`, `nb05_daseot.glb`
- 개인용으로 준비한 저작권 있는 모델은 이 폴더에 넣어도 git에는 올라가지 않습니다(`.gitignore`에서 `*.glb`, `*.gltf`, `*.fbx`, `*.obj` 제외).
- 규격(높이 1m, 원점 발바닥, 앞 방향 -Z)은 `docs/06_dev_plan_and_assets.md` 참고.
